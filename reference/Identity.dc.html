RULES OF THE SYSTEM
01 · HAIRLINES, NOT SHADOWS
Structure comes from 1px lines and grid gaps. No drop shadows, no gradients, no glass.
02 · EVERY VISUAL IS TRUE
Diagrams show real patterns from the work: outbox relay, FSM transitions, trace waterfalls, tenant topology. No abstract blobs.
03 · MOTION IS A SYSTEM RUNNING
Hero: a message travels API → outbox → broker → inbox → worker on a loop; a log line appends per hop. Scroll reveals step state machines. Nothing bounces.
04 · 30-SECOND READ
Nav → hero claim → four capabilities → featured work. A recruiter should know what you do and where you've done it before scrolling past the fold.
05 · RADIUS 4–6, GAP 8/12/24/48
Small radii keep it engineered. Section padding 112px desktop, 72px phone. Max content width 1200px.
06 · VOICE
Terse, declarative, specific. "Make state explicit." No buzzwords, no numbers that aren't yours to publish, no emoji.
