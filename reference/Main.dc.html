Make state explicit

Government processes are state machines whether you model them or not. I model them: every transition named, guarded and recorded, so the audit trail is a by-product, not a feature.

DB TX
OUTBOX
PUBLISH

Write once, deliver reliably

Events are committed in the same transaction as the data, then relayed. Consumers de-duplicate. The result is at-least-once delivery that behaves like exactly-once, with no lost messages during a crash.

auth

If it isn't traced, it isn't done

Every service ships with traces, metrics and structured logs from day one. That stack is how a 429 storm became a one-line fix instead of a week of guessing.
